# polypro

Everything you do on the site, in a fast native window. An unofficial desktop app for Polytoria. Not affiliated with Polytoria.

## Download

Installers for Windows, macOS and Linux live on the releases page. Pick the newest version at the top.

https://github.com/qodelicious/PolyPro/releases

## Windows

Download the setup exe and run it. If SmartScreen warns, click More info and then Run anyway. Needs Windows 10 or 11, 64 bit.

## macOS

Download the dmg or the pkg. The first time you open the app, right click it and choose Open. Needs macOS 14 or newer and works on Apple silicon and Intel.

## Linux

The deb fits Debian and Ubuntu. The AppImage runs anywhere else. Intel and AMD machines only.

## Updating

polypro checks for new versions when it starts. On Windows and macOS it can install the update for you in one click. On Linux, grab the new file from the releases page.

## What you get

* worlds, the store, your character, people, guilds and the forum
* spinnable 3d avatars on profiles and in the customiser
* much faster and lighter than a browser
* updates itself on Windows and macOS

## Privacy

You sign in on polytoria.com itself and the app never sees your password. Usage counts are anonymous and can be turned off in Settings.
